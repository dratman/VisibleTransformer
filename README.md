# VisibleTransformer

A macOS app, written in Swift, that shows in real time what happens inside a
very small GPT-type (transformer) character language model, so a person can
see how such a model works.

## Plan

- A shared Swift library containing a small transformer written from scratch
  (CPU only, no GPU frameworks).
- Small separate prototype programs, one per visual component (for example an
  attention heatmap). Later these are combined into one app.

## Building

Built with Swift Package Manager (no Xcode project). Build instructions will be
added as the code is written.
